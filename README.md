# Folia · 本地版

**只放你自己硬盘里的歌，不联网，不登录。**

</div>

---

## 这是什么

这是 [Folia](https://github.com/chthollyphile/folia-major) 的个人分支。上游是一个围绕在线音乐平台、AI 歌词与多页面播放器做的项目；我把这些全部拆掉，只留下**海报墙**和**本地文件播放**，做成一开机就铺在桌面上的东西。

现在它能做的事，一句话就能说完：**扫描本地音乐文件夹，把封面铺成一面墙，点着放，顺手记下你听了什么。**

---

## 功能

| 能力 | 说明 |
|---|---|
| **本地曲库** | 指向一个文件夹（如 `E:\音乐`），递归扫描 flac / mp3 / m4a 等常见格式 |
| **海报墙** | 以封面为单位的网格，滚动浏览，点封面即播 |
| **壁纸形态** | 窗口沉到桌面最底层，作为动态壁纸长期驻留；本分支只有这一种形态 |
| **内嵌封面** | 只读音频文件里自带的那张图，不做任何在线匹配，删歌重扫也不会认错 |
| **歌词** | 读取同名 `.lrc` 或文件内嵌歌词，纯文本滚动显示（不再有动画可视化） |
| **听歌统计** | 按天、按小时、按歌记录播放次数与时长，导出 `folia-stats.js` 给本地网页画热力图和榜单 |
| **快捷键唤起** | `Ctrl+Alt+Shift+F` 把窗口提到最前并聚焦，避免桌面上误点 |
| **完全离线** | 渲染层把 `fetch` / `XHR` / `WebSocket` / `EventSource` / `sendBeacon` 换成直接失败；主进程用 `session.webRequest` 取消所有 http(s) 请求 |

### 听歌统计怎么看

Folia 会把统计写到 `F:\图片\notes-app\folia-stats.js`，配套的静态页面是同目录下的 `听歌统计.html`——直接双击打开即可，不需要启动任何服务。

页面包含：播放日历热力图、24 小时听歌时钟、按时间范围（上周 / 上月 / 近三月 / 近半年 / 近一年 / 全部）筛选的歌手榜与歌曲榜、点歌手可下钻到他的歌、按次数或时长排序。

## 与上游的对比

| 项目 | 上游 Folia | 本分支 |
|---|---|---|
| 在线音乐平台 | 网易云、QQ、酷狗、汽水、YouTube 等 | **全部移除** |
| 账号登录 | 各平台 OAuth / Cookie | **无登录入口** |
| 网络请求 | 搜索、歌词、封面、AI 均联网 | **一个都不发**（双层拦截） |
| AI 功能 | AI 主题生成、AI 分词、AI 歌词 | **全部关闭** |
| 歌词可视化 | 十余种 WebGL / Pixi 动画样式 | **只保留纯文本样式** |
| 界面结构 | 主页 / 播放器 / 设置 / 队列等多页面 | **只剩海报墙**（其余规划中） |
| 壁纸模式 | 可开关 | **唯一形态，常驻** |
| 封面来源 | 在线匹配 + 内嵌 | **只用内嵌** |
| 遥控窗口 | 独立窗口，手动打开 | 同左（自动唤起规划中） |
| 听歌统计 | 无 | **新增**，按天/按小时/按歌 |
| 唤起方式 | 常规窗口 | **全局快捷键**，防误触 |

## 怎么用

1. 启动 Folia，首次会让你选一个音乐文件夹
2. 扫描完成后，封面会铺满整面墙
3. 点封面播放；`Ctrl+Alt+Shift+F` 可随时把窗口叫到最前
4. 想听歌统计：先播几首，再打开 `听歌统计.html`

---

## 已知限制

- 手动把进度条拖回去重听，不计为新的一次播放（只有自然播完循环才计）
- 不足 5 秒就切走的歌，只记时长不记次数
- 换封面或删歌后，`covers\` 目录里的旧图不会自动清理
- 首次使用时，封面要分几十次逐步拷出，前几次打开统计页可能有些图是空的
